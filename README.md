# Portfolio de Julián Batistutti

Portfolio personal con proyectos reales, enlaces a producción y un espacio interactivo para consultar información sobre mi trabajo.

## Proyectos

- VuelosBaratos
- Tu Matteoli Online
- ¿Qué Cocino Hoy?
- TechPaws

## Desarrollo

```bash
pnpm install
pnpm dev
```

El sitio queda disponible en `http://localhost:3000`.

## Verificación

```bash
pnpm lint
pnpm build
```

## Publicación

El proyecto está preparado para importarse desde GitHub y publicarse en Vercel como una aplicación Next.js.
